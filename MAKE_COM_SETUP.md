# Make.com Integration Guide

This guide will help you connect your AI Chat Assistant to Make.com to send automated AI-powered email responses.

## Overview

Your AI Chat Assistant now has a webhook endpoint that Make.com can call to get AI-generated answers. You can use Make.com to:
- Send AI responses via email (using Gmail, Outlook, or custom SMTP)
- Schedule automated responses
- Trigger AI responses based on various events (form submissions, scheduled times, etc.)

## Webhook Details

**Webhook URL:** `https://250b6b42-11a4-4f26-8ec2-6b7531df9815-00-2bsu6lprbcd7v.riker.replit.dev/webhook/make`

> **⚠️ Important:** The Replit development domain may change if your workspace restarts or is forked. If your webhook stops working, check your Replit URL and update it in Make.com. You can find your current URL by running `echo $REPLIT_DEV_DOMAIN` in the Replit shell or checking the webview URL.

**Method:** POST

**Authentication:** Bearer Token (your WEBHOOK_API_KEY)

**Request Format:**
```json
{
  "question": "Your question here",
  "name": "User Name (optional)"
}
```

**Response Format:**
```json
{
  "success": true,
  "question": "Your question here",
  "answer": "AI-generated answer",
  "name": "User Name"
}
```

## Step-by-Step Setup in Make.com

### 1. Create a New Scenario

1. Log in to [Make.com](https://www.make.com)
2. Click **"Create a new scenario"**
3. Choose your trigger (examples below)

### 2. Choose a Trigger

Here are some popular trigger options:

#### Option A: Schedule (Send AI emails at specific times)
- Search for **"Schedule"** module
- Select **"Schedule"** → **"Every day"** (or your preferred frequency)
- Set the time when you want emails to be sent

#### Option B: Google Forms (Respond to form submissions)
- Search for **"Google Forms"**
- Select **"Watch Responses"**
- Connect your Google account and select your form

#### Option C: Webhooks (Trigger from external systems)
- Search for **"Webhooks"**
- Select **"Custom webhook"**
- Make.com will give you a webhook URL to use in other systems

### 3. Add the HTTP Module to Call Your AI

1. Click the **"+"** button to add a new module
2. Search for **"HTTP"**
3. Select **"HTTP"** → **"Make a request"**
4. Configure the HTTP request:

   **URL:**
   ```
   https://250b6b42-11a4-4f26-8ec2-6b7531df9815-00-2bsu6lprbcd7v.riker.replit.dev/webhook/make
   ```

   **Method:** POST

   **Headers:**
   - Click "Add item"
   - Name: `Authorization`
   - Value: `Bearer YOUR_WEBHOOK_API_KEY` (replace with your actual key)
   - Click "Add item" again
   - Name: `Content-Type`
   - Value: `application/json`

   **Body type:** Raw

   **Request content:**
   ```json
   {
     "question": "What are the benefits of AI?",
     "name": "Scheduled User"
   }
   ```
   
   *Note: You can customize the question field or map it from your trigger data*

5. Click **"OK"**

### 4. Add Email Module to Send the Response

1. Click the **"+"** button to add another module
2. Search for **"Email"**
3. Select **"Email"** → **"Send an Email"**
4. Click **"Create a connection"**
5. Choose your email provider:

#### For Gmail/Google:
- Select **"Gmail"** app instead
- Follow OAuth connection flow
- Grant permissions

#### For Outlook/Microsoft 365:
- Select **"Microsoft 365 Email"** app instead
- Follow OAuth connection flow

#### For Custom SMTP (any email provider):
- Select **"Others"** (custom SMTP)
- Enter your SMTP settings:
  - **SMTP Host:** (e.g., smtp.gmail.com, smtp.office365.com)
  - **Port:** 465 (SSL) or 587 (TLS)
  - **Username:** Your email address
  - **Password:** Your email password or app password
  - **Security:** Use TLS/SSL

6. Configure the email:
   - **To:** Recipient email address
   - **Subject:** `AI Response to: {{question}}`
   - **Content:** Map the `answer` field from the HTTP module response
   - **From:** Your email address

   Example email body:
   ```
   Question: {{question}}
   
   Answer from AI:
   {{answer}}
   
   ---
   Generated by AI Chat Assistant
   ```

### 5. Test Your Scenario

1. Click **"Run once"** at the bottom
2. Check if the email was sent successfully
3. Verify the AI response is correct

### 6. Activate Your Scenario

1. Toggle the switch at the bottom to **"ON"**
2. Your scenario is now active and will run based on your trigger settings

## Troubleshooting

### Error: "Unauthorized"
- Check that you've included the `Authorization` header
- Verify your WEBHOOK_API_KEY is correct
- Format should be: `Bearer YOUR_KEY` (with space after Bearer)

### Error: "Question is required"
- Ensure your request body includes the `question` field
- Check that Content-Type header is set to `application/json`

### Email not sending
- Verify your SMTP settings are correct
- For Gmail, you may need to use an "App Password" instead of your regular password
- Check Make.com execution logs for detailed error messages

### AI response is empty or incorrect
- Verify your OpenAI API key is set correctly in Replit Secrets
- Check the question format is clear and specific
- View workflow logs in Replit for any API errors

## Advanced Tips

### Using Variables in Questions
You can make questions dynamic by mapping data from your trigger:

```json
{
  "question": "Explain {{trigger.topic}} in simple terms",
  "name": "{{trigger.userName}}"
}
```

### Adding Conditional Logic
Use Make.com's Router module to:
- Send different questions based on conditions
- Route responses to different recipients
- Filter when to trigger AI responses

### Rate Limiting
OpenAI has rate limits. For high-volume scenarios:
- Add delays between requests (Make.com "Sleep" module)
- Use error handling to retry failed requests
- Monitor your OpenAI usage dashboard
